# EGOv2 constant-velocity gradient baseline

Base commit: `fc654236127c907db48a9794b8f5e434997d9aa2`.

This directory is an isolated copy. It started from `fc65423` and initially
restored the constant-velocity chain. The current gradient mode now consumes
time-stamped sinusoidal `/dynamic/prediction_<id>` paths generated by the
scene, with two-sample constant velocity retained only as startup fallback.
Dynamic clearance uses the configured `moving_obj_clearance` directly.

The source and binaries under `/home/bob/ALP/guidance/ros_ws` are not used for
EGOv2 planner, trajectory optimizer, environment libraries, scene process, or
target coordinator in this copy. The base workspace is sourced only for ROS
packages that are not built in the copied tracking workspace.

The rebuilt EGOv2 binaries and libraries are under `ros_ws/devel`.

Run the gradient-mode RViz simulation with:

```bash
cd /home/bob/ALP/egov2_fc65423_constvel
./run_constvel_gradient_rviz.sh
```

For a headless check, append `rviz:=false`.

The script defaults to sinusoidal gradient mode. To run the official EGOv2
reactive baseline with the same external visibility statistics:

```bash
NATIVE_EGOV2_MOVING_COST=false \
NATIVE_EGOV2_VISIBILITY_CSV="$PWD/original_visibility.csv" \
NATIVE_EGOV2_LOG_FILE="$PWD/original_rviz.log" \
./run_constvel_gradient_rviz.sh rviz:=false
```
